# Bounce Back Over It

A 2D climbing game made in Unity for a hackathon. You are a rat with a hammer. You swing the hammer with the mouse, stick it into the rocks and pull yourself up a mountain. The goal is to reach the moon. If you fall, you fall a long way.

It is inspired by Getting Over It with Bennett Foddy.

## Controls

* Mouse: aim and swing the hammer. Plant it on a rock and pull yourself up.
* Space: super jump (it uses the yellow charge you build up by landing).
* R: restart.
* Escape: skip the opening.
* Left click: use the menu.
